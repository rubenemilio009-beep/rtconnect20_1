RT CONNECT · CONTRATISTAS RINCÓN

Sitio web estático, responsive y de una sola página.

Para previsualizar: abrir index.html en un navegador moderno. No requiere build ni dependencias JavaScript.
Para publicar: subir index.html y la carpeta assets completa a un hosting estático autorizado por la organización.

NOTAS DE IMPLEMENTACIÓN
- Los enlaces que estaban disponibles en el PDF se conservaron.
- Los enlaces corporativos de SharePoint pueden requerir sesión y permisos.
- El PDF no contiene un enlace asociado al botón “Consultar procedimiento” de Facturación ni al procedimiento de Seguridad Vial o Relaciones Laborales; se identifican como pendientes en vez de inventar destinos.
- La página de Transporte Terrestre del PDF no contiene cronograma ni fechas; la sección deja visible esta limitación.
- La fotografía hero usa una URL pública de Rio Tinto; si el servidor cambia la ruta, reemplazarla por una imagen corporativa autorizada.
- Tipografía: se prioriza “RT Basis” si está instalada/disponible en el entorno corporativo y se incluyen fallbacks. No se redistribuye la fuente propietaria.
